# تقرير تطبيق محاضرة Excel الثانية

## نطاق التنفيذ

تم تطبيق أدوات البحث والتنظيم والتحليل على ملف **Task(5).xlsx**، مع إنشاء نسخة جديدة باسم **Task5_Professional_Report.xlsx**. يتضمن المصنف بيانات مبيعات أصلية مكونة من 10,000 سجل، مع المحافظة على الأوراق الأصلية وإضافة أوراق تحليلية منظمة.

| الأداة | موضع التطبيق | الغرض |
|---|---|---|
| VLOOKUP | ورقة Lookup Tools | استرجاع سعر المنتج من جدول المبيعات |
| XLOOKUP | ورقة Lookup Tools | استرجاع أول منتج مرتبط بمندوب مبيعات |
| HLOOKUP | ورقة Lookup Tools | استرجاع إجمالي مبيعات منطقة من جدول أفقي |
| Pivot Tables | ورقة Pivot Tables | جداول تحليلية حسب المنطقة ومندوب المبيعات |
| Pivot Charts | Dashboard | مخططات مبيعات حسب المنطقة والمنتج |
| Data Validation | Dashboard وLookup Tools | قوائم منسدلة للمنطقة والمندوب والمنتج والسنة |
| Slicer-style controls | Dashboard | مرشحات تفاعلية بصيغة قوائم منسدلة مرتبطة بالمؤشرات |
| Timeline-style controls | Dashboard | تاريخ بداية ونهاية لتحديد الفترة الزمنية |
| Refresh | Dashboard | تعليمات Refresh All وإعادة الحساب بعد تحديث البيانات |

## محتويات المصنف

تحتوي ورقة **Sales Data** على جدول منسق باسم `SalesData`، مع أعمدة مساعدة للشهر والسنة والربع واسم الشهر، وتنسيق شرطي وتجمد صف العناوين. وتعرض ورقة **Dashboard** مؤشرات إجمالي المبيعات، الوحدات، عدد المعاملات، ومتوسط قيمة البيع، بالإضافة إلى تحليل حسب المنطقة والمنتج.

تحتوي ورقة **Lookup Tools** على أمثلة عملية قابلة للتجربة؛ يمكن تغيير القيم من القوائم المنسدلة ومراجعة نتيجة كل دالة. أما ورقة **Pivot Tables** فتحتوي على جداول تلخيصية حسب المنطقة ومندوب المبيعات، مع إجمالي المبيعات وعدد المعاملات والوحدات ومتوسط البيع وترتيب المندوبين.

## طريقة الاستخدام

يمكن تغيير المرشحات في ورقة **Dashboard** من خلايا المنطقة ومندوب المبيعات والمنتج والسنة، كما يمكن تغيير تاريخ البداية والنهاية لتطبيق نطاق زمني. بعد تحديث البيانات المصدرية، استخدم **Data > Refresh All** أو أعد حساب المصنف باستخدام **Ctrl+Alt+F9** حتى تظهر النتائج الجديدة.

> ملاحظة تنفيذية: تم تنفيذ وظيفة Slicer وTimeline بأسلوب تحكم تفاعلي متوافق عبر قوائم Data Validation وحقول تاريخ بداية/نهاية، مع الحفاظ على قابلية فتح الملف في Excel وLibreOffice. ويمكن تحويل هذه الحقول إلى Slicer وTimeline أصليين من داخل Excel Desktop عند الحاجة.
