# Task 5 | Excel for Data Analytics

المادة: SkillEra
النقاط: 50
موعد التسليم: 24 أغسطس

## المطلوب
تطبيق ما تم شرحه في المحاضرة باستخدام أداة تنظيف البيانات على ملف يحتوي على مشكلات.

1. استيراد البيانات إلى أداة تنظيف البيانات وتنظيمها.
2. اكتشاف ومعالجة Duplicate Values وMissing Values وNull Values.
3. تنظيف البيانات من المسافات الزائدة والقيم غير المتسقة.
4. مراجعة عدد الصفوف قبل وبعد التنظيف للتأكد من عدم فقد بيانات مهمة.
5. التعامل مع القيم المفقودة بطريقة مناسبة، مع توضيح سبب اختيار طريقة المعالجة بناءً على طبيعة البيانات.
6. تجهيز البيانات النهائية لتكون صالحة للتحليل.

## التسليم
ملف Excel يحتوي على البيانات قبل التنظيف، وخطوات التنظيف، والبيانات النهائية بعد المعالجة.
